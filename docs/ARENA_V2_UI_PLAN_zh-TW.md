# SnowRealm Games｜SPINREALM 旋界競技場 V2

最後更新：2026-11-20。設計基準為使用者確認的「深藍黑 × 青紫霓虹 × 金色 CTA」全介面規劃圖，以及現有手機截圖反饋。**設計圖是視覺目標，不是已上線功能清單。**

## 一、必須改善的體驗

1. **玩家棋盤優先**：手機縮小對手資訊區；真正的遊戲棋盤、HOLD / NEXT、倒數與觸控鈕不能被戰況卡擠走。
2. **對手自由切換**：棋盤 / 數據，保留偏好。棋盤可看到垃圾行打入與堆疊，數據顯示對手消行與送出，不影響對局規則。
3. **連移精準**：短按只走一步、長按才重複。不要因掉幀補發一串水平操作；DAS / ARR 仍能自訂並驗收鍵盤、觸控與手把。
4. **統一風格**：不是把每個卡片加個紫色外框。大廳、配對、棋盤、商店、好友、會員、設定、多人房都要使用同一套色票與元件語言。
5. **狀態誠實**：只有可用的模式才稱為「已上線」。賽季徽章、任務、金幣或獎勵不可虛構。

## 四、版面規格

### A. 電腦 1024px 以上
- 頂部：SPINREALM 品牌、模式切換、音樂／設定／說明。
- 大廳：金色「開始對戰」、藍紫模式卡、真實狀態提示。
- 對戰：主棋盤最大且居中、左側對手棋盤可切數據、上方倒數與玩家狀態、下方清晰攻防。
- 盡量減少對局中無關 UI 的視覺重量。

### B. 直式手機 320–760px
- 模式導覽最多 3 欄 × 2 列，不擠壓文字或出現橫向捲動。
- CPU／對手縮圖最大約 46–58px 寬，與攻防狀態置於同一緊湊資訊列。
- 主棋盤緊隨對手資訊列，不能出現原手機截圖中大尺寸空棋盤擋路。
- 雙手左右控制、旋轉／軟降／硬降清楚分區，手指可觸及且不重疊；可用單手按鈕自訂為下一階段。
- 起始 Overlay 的主要開始按鈕不能遮蔽整個棋盤太多；長文字收斂、無礙閱讀。

### C. 橫式手機／平板
- 可視寬度充足時採左側對手狀態、右側主競技場。
- 觸控鈕壓縮成短列，避免棋盤只剩小圖。
- 不自動強制螢幕方向，防止瀏覽器權限與設備限制。

## 五、工程驗收與不變條件

- Node 24 GitHub Web CI、桌面安全測試、PWA 打包驗收維持全綠。
- 全部 UI 文案五語完整（繁體／簡體／英／日／韓），不讓中文殘留到英文頁面。
- CPU、練習、道場、道具、排位和登入功能的 ID、事件綁定、碰撞、計分與存檔不能因 CSS／DOM 重排被破壞。
- 真實排位由伺服器結算，前端不創造金幣、段位或成就。
- PWA 修改預快取資產必須升級 Service Worker 版本，避免新舊 CSS 混用。
- 測試通過不等於已用實機視覺驗收；仍需 Android Chrome、iPhone Safari、平板與電腦視窗截圖檢查。
- 會員註冊、錢包、真實多人部署和 Steam 發行，沒有真實端到端驗收不得標為完成。
